# Linguaflow

Перевод речи — из файлов и в реальном времени — между русским, английским и
немецким.

Работает офлайн: распознавание, перевод и озвучка выполняются на вашем
компьютере. Подключение к внешним сервисам — отдельный, явно выбираемый режим.

## Состояние

| День | Что сделано | Коммит |
|---|---|---|
| 0 | Спайк: весь стек замерен на реальном железе | `3893102` |
| 1 | Захват звука, VAD, защита от акустической петли | `cb83f00` |
| 2 | Файловый режим: распознавание, субтитры, экспорт | `f6ff273` |
| 3 | Перевод: офлайн и онлайн, аудит чисел, глоссарий | `e6fb428` |
| 4 | Реальное время: LocalAgreement, темпы, «Разговор» | `4301d62` |
| 5 | Озвучка перевода: дубляж файлов с подгонкой по таймингу | `0b1cf0a` |
| 6 | Интерфейс поверх пайплайна | — |
| 7 | Голоса по говорящему, видео с дорожкой, светлая тема, интерфейс ru/en/de | — |

Окно сейчас из шести экранов: главная, реальное время, браузер, загрузка,
история и настройки. Браузер переводит ролик прямо на странице. В файле
говорящих различает отпечаток голоса, не только высота тона. Дни 6 и 7 и всё,
что сделано после, — это не один коммит; подробности и найденные при
разработке проблемы — в `docs/DAY*.md`.

Окно держит модели в памяти видеокарты. Второе распознавание рядом с
открытым окном на карте около 8 ГБ может не поместиться: на время длинного
прогона из командной строки окно лучше закрыть.

## Языки

Сборка предлагает три: **русский, английский, немецкий**. В каталоге лежат ещё
пять — китайский, японский, испанский, итальянский, французский — со всем, что
им нужно: коды моделей, голоса озвучки, правила переноса строк для письма без
пробелов, числовые шкалы для проверки перевода. Их код написан и покрыт
тестами, просто языки не предлагаются.

Включить любой — одна переменная окружения:

```bash
LINGUAFLOW_LANGUAGES=ru,en,de,zh python tools/transcribe.py video.mp4 --to zh
```

Или постоянно — одна строка в `DEFAULT_ACTIVE` в `lt_core/languages.py`.

## Быстрый старт

```bash
python tools/transcribe.py video.mp4                    # расшифровка
python tools/transcribe.py video.mp4 --to de            # + перевод, офлайн
python tools/transcribe.py video.mp4 --to de --bilingual
python tools/transcribe.py video.mp4 --to ru --voice     # + озвучка и видео
python tools/transcribe.py video.mp4 --to ru --voice --one-voice
python tools/audio_check.py devices                     # проверка устройств
python tools/app.py                                     # интерфейс
```

## Установщик

Windows, из корня репозитория, тем же окружением, в котором стоят зависимости:

```bash
.venv\Scripts\python.exe packaging\build_installer.py
```

Готовые файлы — в `packaging\output\`: `Linguaflow-setup.exe` и, если
установщик больше 4 ГБ, части `Linguaflow-setup-*.bin` рядом с ним. Запускается
exe, части должны лежать в той же папке. Программа ставится в Program Files:
рядом с ней модели, в `%APPDATA%\Linguaflow` — настройки, история и ключ.
Нужен Inno Setup 6 (`ISCC.exe`).

## Перевод: где выполняется

| Режим | Провайдер | Что нужно | Куда уходит текст |
|---|---|---|---|
| `offline` (по умолчанию) | NLLB-200 локально | ничего | никуда |
| `online` | DeepL | `DEEPL_API_KEY` | в DeepL |
| `online` | Groq | `GROQ_API_KEY` | в Groq |
| `online` | OpenAI | `OPENAI_API_KEY` | в OpenAI |
| `online` | свой сервер | адрес эндпоинта | никуда, если это localhost |

Режим не переключается сам. «Офлайн» — обещание о том, где остаются ваши
слова, а не предпочтение по качеству.

## Требования

Windows 11, Python 3.12, видеокарта NVIDIA (работает и без неё, медленнее).
Модели скачиваются при первом запуске в `models/` (~4 ГБ).

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```
