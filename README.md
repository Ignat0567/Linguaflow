# Linguaflow

Перевод речи — из файлов и в реальном времени — между восемью языками:
английский, немецкий, русский, китайский, японский, испанский, итальянский,
французский.

Работает офлайн: распознавание, перевод и озвучка выполняются на вашем
компьютере. Подключение к внешним сервисам — отдельный, явно выбираемый режим.

Подробности и найденные при разработке проблемы — в `docs/DAY*.md`.

## Быстрый старт

```bash
python tools/transcribe.py video.mp4                    # расшифровка
python tools/transcribe.py video.mp4 --to de            # + перевод, офлайн
python tools/transcribe.py video.mp4 --to de --bilingual
python tools/audio_check.py devices                     # проверка устройств
```

## Перевод: где выполняется

| Режим | Провайдер | Что нужно | Куда уходит текст |
|---|---|---|---|
| `offline` (по умолчанию) | NLLB-200 локально | ничего | никуда |
| `online` | DeepL | `DEEPL_API_KEY` | в DeepL |
| `online` | Groq | `GROQ_API_KEY` | в Groq |
| `online` | OpenAI | `OPENAI_API_KEY` | в OpenAI |
| `online` | свой сервер | адрес эндпоинта | никуда, если это localhost |

Режим не переключается сам. «Офлайн» — обещание о том, где остаются ваши
слова, а не предпочтение по качеству.

## Требования

Windows 11, Python 3.12, видеокарта NVIDIA (работает и без неё, медленнее).
Модели скачиваются при первом запуске в `models/` (~4 ГБ).

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```
